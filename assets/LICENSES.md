# 资产与许可记录

本项目（Grow · 向光而生，P0 第一章）的所有交付资产均为本团队自制，不含第三方美术、音频或字体文件。

| 类别 | 来源 | 许可 |
| --- | --- | --- |
| 代码（scripts/、tools/、tests/） | 本项目编写 | 项目自有，随仓库提交 |
| 音效与环境声 | `scripts/view/audio_bank.gd` 程序化 PCM 合成（正弦/噪声/包络），无采样素材 | 项目自有 |
| 视觉表现 | `scripts/view/world_view.gd`、`hud.gd` CanvasItem 程序绘制，无贴图资产 | 项目自有 |
| 字体 | Godot 引擎内置默认字体，未嵌入第三方字体文件 | 随引擎分发 |
| 引擎 | Godot 4.7.2 stable | MIT License，见 https://godotengine.org/license |

若后续引入任何外部素材（贴图、音频、字体），必须在此表追加名称、来源、作者、许可与链接，并确认许可允许在 Windows 独立包中再分发。
