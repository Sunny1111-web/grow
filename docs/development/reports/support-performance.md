## 变更及规则保持

仅优化 `scripts/core/support_solver.gd`，并新增 `tests/test_support_equivalence.gd` 与小规模测试专用的 `tests/fixtures/reference_support.gd`。参考文件保留优化前的逐边遍历求解代码，不进入生产调用链。既有文件的每次替换均由 `tools/safe_write.py` 将完整原文件迁移至 `C:/backup/2026年9月5日` 并追加 `C:/backup/log.txt` 后写入。

原算法逐边遍历所有未锚定后代，长链复杂度为 O(E² + E×L)。新算法将非根、远端未锚定边组成森林，使用迭代 DFS 把边的弧长中点重量及远端普通叶重量排成连续区间；后序递推该边长度加子树最长弧长。两个坐标轴分别离线排序负载与查询原点，Fenwick 树求区间内位于原点左侧的重量与加权坐标和。

每轴使用恒等式 `Σw|x-o| = S - oW + 2(oW_left - S_left)`，所以左右、上下负载均计绝对值，不会把相反方向负载抵消。总弯矩仍为 `Mx + .25My + .1W`。弧长中点函数保持原样；根排除、远端锚点完整隔离及其后代另起悬空区、应急叶独立固定、普通叶重 .25、强化枝重 .45×长度、藤重 .25×长度，以及 Dcap/Mcap 全部保持原值。输出器官 ID、顺序与输入不被修改也纳入差分断言。

设 P 为几何点数、N 为负载数，新时间复杂度为 O(P + (E+N)log(E+N))，临时空间 O(E+N)。没有降低400边/100叶上限，没有跳过求解或修改风险规则。
